# MP2 REST API

This project is a FastAPI-based application that converts my MP1 data pipeline into a REST API. GET /health serves as a health check API endpoint. Clients can feed a CSV file with POST /upload, which will save it to memory and return a unique ID, number of records, and columns. With GET /datasets/{dataset_id}, users can get the stored rows, and the limit query parameter decides how many rows are returned. With POST /datasets/{dataset_id}/process users can validate and cleanse a stored dataset using my MP1 modules in data_pipeline/ and get a cleansing report. There is a log for every request with request_id, status_code, and duration, and the request ID is also returned in the X-Request-ID header. Tests for the API are in tests/ and can be executed using python -m pytest tests -v.
